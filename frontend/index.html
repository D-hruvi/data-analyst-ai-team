Engineering Architecture & Invariants Specification
RFC-2026-DA01 · Single Agent vs Multi-Agent Orchestration on Pandas Analytics

1. Core System Invariant: Language models are never permitted to execute code or access host resources directly. All code execution occurs inside an ephemeral Docker container governed by app/sandbox.py.

System Architecture & Execution Topologies
Security Boundary Docker Isolation Flag Enforcement Rationale
Network Egress --network none Prevents data exfiltration or external socket calls from generated code.
User Privilege UID 1000 (non-root) Eliminates root-level container escalation or daemon breakout capabilities.
Filesystem Integrity --read-only Ensures generated scripts cannot persist malicious binaries or alter sandbox base.
Kernel Capabilities --cap-drop ALL Strips all Linux capabilities (raw sockets, audit, sys_admin).
Memory Quota --memory 512m Guards host against denial-of-service from infinite loops or allocation bombs.
Execution Timeout 15 seconds SIGKILL Kills runaway processes and terminates unresponsive container instances.
Empirical Benchmark Takeaway (Ceiling & Overhead Analysis)
Summary of Findings from 50-Question Frozen Evaluation

• Self-Correction beats Coordination: Baseline 2 (Single Agent with 3-attempt feedback) achieved 100.0% accuracy (50/50). Multi-Agent Team achieved 96.0% (48/50).

• The Cost Overhead of Multi-Agent: Team required 3.6x more tokens (3,543 vs 978 mean) and 3.5x higher cost ($0.0171 vs $0.0049 total) due to redundant prompt schemas between Planner, Coder, Reviewer, and Explainer.

• Failure Breakdown: Baseline 1 only failed 3 chart questions because it forgot to assign result = .... Baseline 2 caught this execution error in the sandbox and corrected it on retry 1 without requiring planner/reviewer overhead.
